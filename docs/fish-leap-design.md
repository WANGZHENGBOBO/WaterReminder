# 小鱼偶尔跃水

已确认：Apple 芯片版先做；水未满且鱼已出现时，每天最多 3 次，以轻跃为主、偶尔较高；鱼露出水面的部分使用主水面色值，落水有克制的小水花。弹窗关闭时不计时、不补播；减少动态效果时关闭。尾巴摆动维持原样。

方案：保留现有鱼形与水波，在 `WaterMotion` 中计算一段可测试的跃水轨迹；SwiftUI 只负责按本地可见时间稀疏触发、分水上水下着色和绘制短暂水花。相比另建粒子引擎，这与现有 30 fps 水面一致、改动更小；相比按全天固定时刻触发，用户关闭弹窗时不会错过或重新打开后连播。

约束：本地记录每日次数和上次跃水时间；水位太低或接近满时不触发；同时只跃一条鱼；每次间隔至少两小时；无网络、无新的权限。正常饮水记录及设置不变。

同轮视觉修正：菜单栏弹窗外轮廓参考 macOS 电池弹窗圆角，内层水位卡片保持原形状。
