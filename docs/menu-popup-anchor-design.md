# 菜单栏弹窗顶部锚定

用户期望：展开或收起今日记录、历史趋势时，弹窗上沿始终贴着菜单栏，只有底边移动。现有 SwiftUI `MenuBarExtra(.window)` 在内容高度变化后自行居中，即使事后监听窗口尺寸和位置也会重新偏移，已由用户两次截图确认。

改用 AppKit `NSStatusItem` 管理入口、透明无标题 `NSPanel` 承载原有 `DashboardView`。SwiftUI 仍负责所有内容与记录；内容报告理想尺寸，控制器每次按状态栏按钮的屏幕坐标一次性设置面板大小与位置。面板顶部取按钮下缘，水平尽量居中并限制在可见屏幕内。点击外部收起；设置、退出等原有动作保留。现有水量数据目录和交付包格式不变。

验证：几何单元测试覆盖展开、收起、窄屏钳制；核心检查和应用构建通过；本机交互仍需人工目视确认，不以构建成功冒充视觉验证。
