# iPhone 独立事件文件同步设计

## 目的

绕开 iPhone 快捷指令在“追加到文件”动作中丢失输入的问题，让手机与 Mac 的喝水记录可靠双向一致。

## 方案

- iPhone 每次记录生成唯一 ID，并把一条完整 JSON 喝水事件保存为 `喝水BO～/Sync/Events/<ID>.json`。
- Mac 保留现有共享 CSV，同时每 5 秒扫描 `Events`，校验、按记录 ID 去重并合并到本地记录。
- Mac 继续发布 `today-summary.json`；快捷指令只读取其中的 Mac 目标值和今日进度。
- 空文件、损坏 JSON、非法水量和重复事件均忽略，不能阻塞其他记录。

## 取舍

- 采用独立事件文件：没有共享文件并发追加，单条失败不会损坏其他记录。
- 不采用双追加日志：水量与时间可能错位。
- 不依赖第三方服务；数据仍只在用户自己的 iCloud Drive 中。

## 验收

- 快捷指令不包含 `Append File` 写入动作。
- 生成的保存动作直接接收 JSON 文本动作输出。
- Mac 能导入有效 iPhone 事件，忽略空文件，并保证重复扫描不重复计数。
- 手机记录后，Mac 打开时通常在 iCloud 到达后 5 秒内更新。
