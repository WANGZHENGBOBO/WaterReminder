# Fish Leap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add rare natural fish leaps and splash to the Apple Silicon menu bar gauge.

**Architecture:** Pure `WaterMotion` geometry and eligibility; `WaterGaugeView` schedules while visible and renders the same fish silhouette in water/air colors. Daily cap and last trigger live in local preferences, not the app bundle.

**Tech Stack:** SwiftPM, SwiftUI, Foundation.

**Spec:** `docs/fish-leap-design.md`

## Global Constraints

- Apple Silicon only; leave Intel package unchanged.
- No network or extra permissions; no user state in ZIP.
- Honor Reduce Motion and preserve existing tail motion.

## Review Focus

- Near-empty and near-full water: no leap if geometry has too little room.
- Menu bar closed: no missed-event queue or immediate catch-up.
- Multiple fish: exactly one leaps at a time.
- Clock/day rollover: daily count resets; prior day does not replay.
- Wave colors and waterline: fish color split matches current wave and custom base hex.
