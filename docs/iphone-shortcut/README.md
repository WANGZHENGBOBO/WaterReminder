# 在 iPhone 和 Apple Watch 上记录喝水

配套文件有两个：`喝水BO～.shortcut` 负责记录和同步；`喝水BO～ 手表.shortcut` 是手表上的轻量入口。都不需要会员或第三方服务器。记录先保存在你自己的 iCloud Drive 中；同一 Wi‑Fi 下还会尝试直接发给 Mac，局域网不可用时自动由 iCloud 补齐。

## 安装

1. 在 Mac 上打开「喝水BO～」，在欢迎页点击“发送 iPhone 版”和“发送手表版”。
2. 通过隔空投送或其他方式，把 App 随附的 1.2.3 两个快捷指令文件发送到 iPhone。
3. 在 iPhone 上打开 `喝水BO～`，点“添加快捷指令”；已经安装旧版时选择“替换快捷指令”。
4. 再打开 `喝水BO～ 手表` 并添加。两个文件都需要安装。
5. 第一次运行 `喝水BO～` 时，iOS 会询问是否允许访问 iCloud 中的「快捷指令」文件夹。点“始终允许”；快捷指令只使用 `Shortcuts/喝水BO～/Sync`，不会读取其他文件。
6. 在 `喝水BO～` 的详情 → 隐私里开启“允许在锁定时运行”，iPhone 放在口袋里也能处理手表传来的水量。
7. 在 Apple Watch 的快捷指令详情中只显示 `喝水BO～ 手表`；`喝水BO～` 不直接显示在手表上。

全新安装的 Mac 版默认开启同步，不需要再去设置里打开开关。旧版本升级时如果原本没有开启同步，仍会保持本地模式；可以在设置中主动开启，或从欢迎页重新查看引导。

如果更新或重新安装快捷指令后系统又询问一次，同样点“始终允许”。这是 iOS 对快捷指令文件访问的授权提示，不是登录、付费或上传数据。

以 App 当前随附的快捷指令文件为准。

## Apple Watch 怎么用

打开手表上的 `喝水BO～ 手表`：

- 水量默认是 `197ml`，正好一杯时直接点确认。
- 需要其他水量时，直接调整数字再确认；允许范围是 `1...2000`。
- 手表没有菜单，也不显示今日记录。
- 手表只把 `drink:<水量>` 交给 iPhone。iCloud 文件读写、局域网请求和通知都由 iPhone 完成。

因此手表和 iPhone 需要保持连接；本功能不使用手表直接连接 Mac。若手表只显示系统远程执行错误，先确认 `喝水BO～` 已安装、内容未改名，并在 iPhone 解锁时从手表成功运行一次以完成授权。

## iPhone 怎么用

运行时会先出现三个选择：

- `喝了 197ml`：直接按默认的一杯记录。
- `自定义水量`：输入这一次实际喝了多少 ml。
- `查看今日记录`：查看当天累计进度和逐次记录，不会新增水量。同一 Wi‑Fi 下会直接从 Mac 读取最新汇总，不等待 iCloud 上传；离开同一网络时读取 iCloud 汇总，汇总暂不可用时再从共享记录计算。
- 历史记录用 `M1`、`M2`、`iPH` 区分电脑和手机；电脑短后缀可以在 Mac 设置中修改。

每次记录后会先发送到同一 Wi‑Fi 下的 Mac，再用一条不阻塞的通知显示本次水量、今日累计、完成百分比和剩余水量。通知会自动消失，不需要再点结果页；离线记录会在 iCloud 恢复后补上。

Mac 同步时还会写入 `settings.json` 和 `today-summary.json`。每日目标以 Mac 设置为准；汇总文件包含当天累计量、目标、每次记录的时间与水量，以及已合并的手机记录数量。手机端据此显示进度，并避免重复统计已经由 Mac 合并的记录。

每次喝水会作为唯一 JSON 事件保存到 `Sync/Events`，避免多个设备同时改写同一个共享文件。同一 Wi‑Fi 下快捷指令会在保存 iCloud 事件后，向 `Sync/Devices` 中当前可用 Mac 发送同一事件；失败不会影响 iCloud 记录。Apple 可能把纯文本事件保存成 `.txt` 扩展名，Mac 会按内容校验并只导入一次。

如果升级前快捷指令曾留下旧日志，可以保留；Mac 会兼容并迁移旧记录，迁移前会备份原文件。

如果手机和 Mac 显示不一致，请依次检查：

1. Mac 版设置中“使用 iCloud 同步 iPhone 快捷指令”已开启。
2. Mac 应用正在运行，并已更新到 1.2.3 或更高版本。
3. iPhone 安装的是上面的最新 1.2.3 两个快捷指令。
4. 两个设备都使用同一个 iCloud 账户，快捷指令可访问 `Shortcuts/喝水BO～/Sync`。
5. 如果是多台 Mac，确认目标电脑的 `Devices` 设备文件已同步，并检查设置页是否显示局域网地址。

## 隐私与卸载

- 不连接开发者服务器，不收集账号、定位、设备信息或喝水记录。
- 数据只在你的 Apple 设备和个人 iCloud Drive 之间同步。
- 删除快捷指令不会删除已经同步的记录。若希望同时清空 iPhone 端的同步日志，可自行删除 iCloud Drive 的 `Shortcuts/喝水BO～` 文件夹。
- 安装包中不含作者或测试用的喝水记录。
