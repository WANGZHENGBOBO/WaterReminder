# 在 iPhone 上记录喝水

`喝水BO～.shortcut` 是配套的 Apple 快捷指令，不需要会员，也不需要第三方服务器。记录只保存在你自己的 iCloud Drive 中，Mac 端读取后会合并进「喝水BO～」。

## 安装

1. 把 `dist/喝水BO～.shortcut` 通过隔空投送或 iCloud Drive 发到 iPhone。
2. 在 iPhone 上点开文件，选择“添加快捷指令”。
3. 第一次运行时允许它访问 iCloud Drive；它只会使用 `Shortcuts/喝水BO～/Sync` 文件夹。
4. 在快捷指令详情里选择“添加到主屏幕”，以后点一下就能记录。
5. 在 Mac 版设置中打开“使用 iCloud 同步 iPhone 快捷指令”。

运行时会先出现两个选择：

- `喝了 197ml`：直接按默认的一杯记录。
- `自定义水量`：输入这一次实际喝了多少 ml。

快捷指令会分别追加水量与发生时间。Mac 打开时会自动同步；离线记录会在 iCloud 恢复后补上。Mac 上的目标、历史趋势和导出功能保持不变。

## 隐私与卸载

- 不连接开发者服务器，不收集账号、定位、设备信息或喝水记录。
- 数据只在你的 Apple 设备和个人 iCloud Drive 之间同步。
- 删除快捷指令不会删除已经同步的记录。若希望同时清空 iPhone 端的同步日志，可自行删除 iCloud Drive 的 `Shortcuts/喝水BO～` 文件夹。
- 安装包中不含作者或测试用的喝水记录。
