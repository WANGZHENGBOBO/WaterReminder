# 在 iPhone 和 Apple Watch 上记录喝水

> 当前采用手表快捷指令方案，手表只在和 iPhone 一起使用时记录。手表通过 iMessage 给自己发一条消息，再由 iPhone 完成保存和同步；按下面的设置关闭短信与 RCS 回退后，不会使用短信。`WaterCompanion/` 配套 App 保留在仓库中，但当前不作为安装要求。

配套文件有三个：`喝水BO～.shortcut` 负责手机手动记录；`喝水BO～ 接收.shortcut` 是自动化专用接收器；`喝水BO～ 手表.shortcut` 是手表上的水量输入入口。手表把 `drink:喝水BO～<水量>` 通过 iMessage 发到你自己的 Apple ID 邮箱；iPhone 的“收到消息”自动化执行 `喝水BO～ 接收`，完成 iCloud 写入。

## 安装

1. 在 Mac 上打开「喝水BO～」，在欢迎页点击“发送 iPhone 版”“发送接收版”和“发送手表版”。
2. 通过隔空投送或其他方式，把 App 随附的三个 1.2.4 快捷指令文件发送到 iPhone。
3. 在 iPhone 上打开 `喝水BO～`，点“添加快捷指令”；已经安装旧版时选择“替换快捷指令”。
4. 再打开 `喝水BO～ 接收` 并添加。它只给自动化使用，不要在手表上执行。
5. 最后打开 `喝水BO～ 手表` 并添加。导入时填写自己的 Apple ID 邮箱，手表会用它通过 iMessage 给自己的 iPhone 发一条消息。手表上只保留这一条。
6. 在 iPhone 的“快捷指令 → 自动化”中新建“收到消息”：发件人选择自己，消息包含 `喝水BO～`，设为“立即运行”。自动化执行 `喝水BO～ 接收`，并把动作的输入设为“快捷指令输入”，不要留空。
7. 第一次运行 `喝水BO～` 时，iOS 会询问是否允许访问 iCloud 中的「快捷指令」文件夹。点“始终允许”；快捷指令只使用 `Shortcuts/喝水BO～/Sync`，不会读取其他文件。
8. 打开 `喝水BO～` 的详情，开启“允许在锁定时运行”。
9. 在 iPhone 的“设置 → App → 信息”中关闭“以短信发送”；旧版 iOS 的路径是“设置 → 信息”。如果存在“RCS 信息”开关，也一并关闭。这样 iMessage 不可用时只会发送失败，不会退回短信或 RCS。

## 只走 iMessage，不发送短信

快捷指令的“发送消息”动作没有“仅 iMessage”开关。它会优先使用 iMessage，但是否回退到短信由 iPhone 的“信息”设置决定：

- 关闭“以短信发送”后，iMessage 不可用时消息不会改走短信。
- 如果系统提供“RCS 信息”开关，也请关闭，避免改走运营商消息。
- 手表和 iPhone 一起使用时，保持两台设备联网并登录同一个 Apple ID。发送地址填写这个 Apple ID 的邮箱，确认消息气泡为 iMessage 蓝色。
- 如果 iMessage 没有送达，这次记录不会进入 Mac；不会出现“绿泡泡短信已经发出、但手机自动化没收到”的不确定状态。

全新安装的 Mac 版默认开启同步，不需要再去设置里打开开关。旧版本升级时如果原本没有开启同步，仍会保持本地模式；可以在设置中主动开启，或从欢迎页重新查看引导。

如果更新或重新安装快捷指令后系统又询问一次，同样点“始终允许”。这是 iOS 对快捷指令文件访问的授权提示，不是登录、付费或上传数据。

以 App 当前随附的快捷指令文件为准。

## iPhone 怎么用

运行后只出现一个水量输入：

- 默认数字是 `197ml`，不需要先选“默认”或“自定义”。
- 正好喝了一杯就点确认；杯量不同就直接修改数字，再点确认。
- 提交后会先保存一条带水量的记录，再显示本次水量、今日累计、完成百分比和剩余水量。

记录同时保存到 iCloud，并优先发送到同一 Wi‑Fi 下的 Mac。进度用一条不阻塞的通知显示，会自动消失，不需要再点结果页；离线记录会在 iCloud 恢复后补上。逐次历史和进度仍可在 Mac 的“今日记录”中查看。

Mac 同步时还会写入 `settings.json` 和 `today-summary.json`。每日目标以 Mac 设置为准；汇总文件包含当天累计量、目标、每次记录的时间与水量，以及已合并的手机记录数量。手机端据此显示进度，并避免重复统计已经由 Mac 合并的记录。

每次喝水会作为唯一 JSON 事件保存到 `Sync/Events`，避免多个设备同时改写同一个共享文件。同一 Wi‑Fi 下快捷指令会在保存 iCloud 事件后，向 `Sync/Devices` 中当前可用 Mac 发送同一事件；失败不会影响 iCloud 记录。Apple 可能把纯文本事件保存成 `.txt` 扩展名，Mac 会按内容校验并只导入一次。

## Apple Watch 怎么用

- 打开 `喝水BO～ 手表`，水量默认 `197ml`，可直接确认或修改数字。
- 手表不读写 iCloud，只把水量通过 iMessage 发给同一位用户的 iPhone。
- iPhone 的消息自动化收到后执行 `喝水BO～ 接收`，完成保存并显示今日进度通知。
- 手表和 iPhone 需要保持配对；第一次使用前，务必把消息自动化设为“立即运行”，并运行一次手机捷径完成 iCloud 与局域网授权。

如果消息自动化没有反应，先确认发件人确实是自己、消息里包含 `喝水BO～`，并且自动化没有被系统要求“运行前询问”。再确认 iPhone 的“以短信发送”和 RCS 回退已关闭，消息气泡是 iMessage 的蓝色。直接在手机消息中给自己发一条 `drink:喝水BO～197` 可以单独测试手机自动化。

如果手表发给自己的 Apple ID 邮箱，而自动化里设置了“发件人是我”，请把这个邮箱加入自己的联系人名片，或者暂时去掉发件人条件、只保留消息内容包含 `喝水BO～`。否则邮件地址可能无法匹配“自己”，消息收到了但自动化不执行。只填 Apple ID 邮箱，不要改填手机号。

如果升级前快捷指令曾留下旧日志，可以保留；Mac 会兼容并迁移旧记录，迁移前会备份原文件。

如果手机和 Mac 显示不一致，请依次检查：

1. Mac 版设置中“使用 iCloud 同步 iPhone 快捷指令”已开启。
2. Mac 应用正在运行，并已更新到 1.2.4 或更高版本。
3. iPhone 安装的是上面的最新 1.2.4 快捷指令。
4. 两个设备都使用同一个 iCloud 账户，快捷指令可访问 `Shortcuts/喝水BO～/Sync`。
5. 如果是多台 Mac，确认目标电脑的 `Devices` 设备文件已同步，并检查设置页是否显示局域网地址。

## 隐私与卸载

- 不连接开发者服务器，不收集账号、定位、设备信息或喝水记录。
- 数据只在你的 Apple 设备和个人 iCloud Drive 之间同步。
- 删除快捷指令不会删除已经同步的记录。若希望同时清空 iPhone 端的同步日志，可自行删除 iCloud Drive 的 `Shortcuts/喝水BO～` 文件夹。
- 安装包中不含作者或测试用的喝水记录。
